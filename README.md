## 📚 Tips for Better Picture Books

- **Keep pages short** - Less text per page means bigger, more impactful illustrations
- **Use descriptive words** - The AI works better with vivid language like "sparkling" instead of "shiny"
- **Stick to one theme** - Choose a single setting or palette (like "underwater" or "autumn forest") for consistency
- **Review character descriptions** - Mention your main character's look on the first page so the AI remembers it
- **Read aloud while writing** - If it sounds good spoken, it'll look great illustrated!
